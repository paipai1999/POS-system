# ဆိုင်တွင် စတင်သုံးမည့် စစ်ရန်စာရင်း

ဤစာရင်းကို ပုံနှိပ်ပြီး တစ်ခုချင်း စစ်ကာ ✔ ခြစ်ပါ။ (အင်္ဂလိပ်ဘာသာ ဗားရှင်း – [SETUP-CHECKLIST.md](SETUP-CHECKLIST.md)၊ နေ့စဉ်လုပ်ငန်းစဉ်ကို [OWNER-GUIDE-my.md](OWNER-GUIDE-my.md) တွင် ကြည့်ပါ။)

**ဘာကို စမ်းပြီးပြီ၊ ဘာကို မစမ်းရသေးလဲ**
- စမ်းပြီး: Linux ပေါ်တွင် test ၃၇၂ ခု အားလုံး အောင်သည်။ ဘရောက်ဇာအစစ်ဖြင့် မျက်နှာပြင်များ (ကွန်ပျူတာနှင့် ဖုန်းအရွယ်) ကို ကြည့်ထားသည်။
- **မစမ်းရသေး**: Windows ပေါ်ရှိ `.bat` ဖိုင်များ၊ ဖုန်းအစစ်ဖြင့် ဆိုင်၏ Wi-Fi၊ ပြေစာပရင်တာအစစ်၊ မြန်မာစာကို မြန်မာစကားပြောသူ ဖတ်ခြင်း။ ဤစာရင်း၏ အပိုင်း ၁၊ ၂၊ ၅ နှင့် ၆ သည် ထိုအချက်များကို စစ်ရန်ဖြစ်သည်။

ဆာဗာအတွက် ဘာမျှ install လုပ်ရန် မလိုပါ၊ Node.js **22.5 သို့မဟုတ် ပိုမြင့်** (LTS) ရှိရန်သာ လိုသည်။

---

## ၁။ ကောင်တာ PC (ဆိုင်မဖွင့်မီ)

- [ ] `start-server.bat` ကို နှိပ်ပြီး `http://localhost:3000` ပွင့်သည်။ (Node ဗားရှင်းဟောင်းလျှင် ဘာသတိပေးသည်ကို မှတ်ထားပါ။)
- [ ] `allow-firewall.bat` ကို **administrator ဖြင့်** (right-click → Run as administrator) တစ်ကြိမ် run ပြီးပြီ။
- [ ] Windows တွင် Wi-Fi ကွန်ရက်ကို **Private** ဟု သတ်မှတ်ထားသည်။ (Public ဖြစ်နေလျှင် ဖုန်းများ မချိတ်နိုင်ပါ။)
- [ ] router တွင် ဤ PC အတွက် **DHCP reservation** လုပ်ထားသည်။ (လိပ်စာပြောင်းလျှင် ဖုန်းများနှင့် စားပွဲ QR ကုဒ်များ မရတော့ပါ။)
- [ ] ဖုန်းတစ်လုံးဖြင့် "Other devices" လိပ်စာ (ဥပမာ `192.168.1.20:3000`) ကို ဆိုင်၏ Wi-Fi ပေါ်မှ ဖွင့်ကြည့်ပြီး ပွင့်သည်။
- [ ] `install-autostart.bat` ကို တစ်ကြိမ် run ပြီး PC ကို restart လုပ်ကြည့်သည်။ ဆာဗာ ကိုယ်တိုင် ပြန်တက်လာသည်။ (လူမရှိဘဲ မီးပြတ်ပြီးပြန်လာသည့် PC အတွက် Windows ကို အလိုအလျောက် sign-in လုပ်ရန်လည်း သတ်မှတ်ပါ – README ကြည့်ပါ။)
- [ ] **Settings → System health** ကိုဖွင့်ပါ။ Backup နှင့် disk နေရာ ပြချက်များ ယုတ္တိရှိသည်။ (ဤစစ်ချက်ကို Windows ပေါ်တွင် မစမ်းရသေးပါ။)
- [ ] **Settings → Data & backup → Backup folders** တွင် USB သို့မဟုတ် cloud (OneDrive / Google Drive / Dropbox) folder ထည့်ထားသည်။
- [ ] **Back up now** ကို နှိပ်ပြီး ထို folder ဘေးတွင် **"Different disk ✓"** ပေါ်သည်။ (မပေါ်လျှင် backup သည် PC ဒစ်ခ်ထဲတွင်သာ ရှိနေပြီး ဒစ်ခ်ပျက်လျှင် ဒေတာနှင့် backup အတူပျက်မည်။)
- [ ] `restore-backup.bat` ကို **ဒေတာအစစ် မဝင်မီ** တစ်ကြိမ် လေ့ကျင့်ပြီး ဆာဗာပြန်စတင်ကာ ပြန်ရသည်ကို မြင်ပြီးပြီ။ (ပြန်သိမ်းမီ ရှိပြီးသားဒေတာကို `before-restore-…` အဖြစ် သိမ်းပေးသည်။)
- [ ] ဆာဗာ PC အတွက် **UPS အသေးစား** ရှိသည် (မီးပြတ်၍ ဒေတာဘေ့စ်မပျက်စေရန်)။

## ၂။ ပြေစာပရင်တာ

- [ ] `open-counter.bat` ဖြင့် ကောင်တာကို ဖွင့်သည်။ **Settings** တွင် **"This device is the printer station"** ကို အမှန်ခြစ်ထားသည်။
- [ ] **Settings → Printing → Print test page** ကို ပြေစာပရင်တာအစစ်ဖြင့် နှိပ်သည်။ စက္ကူ **80 mm**၊ margin **None** ရွေးပါ။
- [ ] စက္ကူဖြတ်သည်၊ စာကြောင်းများ မကျော်၊ **မြန်မာစာ** ပုံမှန်ပေါ်သည်။
- [ ] မီးဖိုချောင်လက်မှတ် (ဖွင့်ထားလျှင်) နှင့် ပြေစာ တကယ်ထွက်သည်။
- [ ] အပို စက္ကူလိပ် တစ်လိပ် အံဆွဲထဲတွင် ရှိသည်။

## ၃။ ဝန်ထမ်းနှင့် PIN

- [ ] demo PIN (1234၊ 1111၊ 2222၊ 3333) အားလုံးကို ကိုယ်ပိုင် PIN (၄–၆ လုံး) သို့ ပြောင်းပြီးပြီ။ (ဆာဗာကိုယ်တိုင်လည်း မပြောင်းမချင်း ဘာမျှ မလုပ်ခိုင်းပါ။)
- [ ] **Staff** တွင် အမည်များကို တကယ့်အမည်ဖြင့် ပြင်ထားပြီး ထွက်သွားသူများကို *Active* ပိတ်ထားသည် (မဖျက်ပါနှင့်)။
- [ ] **System health** တွင် demo PIN မကျန်တော့ကြောင်း ပေါ်သည်။
- [ ] ဝန်ထမ်းတစ်ဦးစီ၏ **တစ်နာရီလုပ်ခ** ကို *Staff → Edit* တွင် ထည့်ပြီးပြီ။ (ထည့်မှ Hours နှင့် Business health တွင် လုပ်ခ ပေါ်မည်။)
- [ ] တစ်ဦးချင်း၏ PIN ကို မျှဝေမထားပါ။ မန်နေဂျာများကသာ လျှော့စျေး၊ ပယ်ဖျက်၊ ပြန်အမ်းကို ခွင့်ပြုကြောင်း ဝန်ထမ်းများ သိသည်။

## ၄။ မီနူးနှင့် ဆက်တင် (အမေ့လွယ်ဆုံး)

- [ ] ပါလာသော **demo မီနူး** (Espresso၊ Latte…) ကို သင့်မီနူးအစစ်ဖြင့် အစားထိုး သို့မဟုတ် ဖျက်ပြီးပြီ။
- [ ] ဈေးနှုန်းများ မှန်ကန်သည်။ **အခွန် %** နှင့် **ဝန်ဆောင်ခ (service charge)** ကို သတ်မှတ်ပြီးပြီ။
- [ ] ငွေကြေးပုံစံ မှန်သည် (ကျပ်ဆိုလျှင် ဒသမ ၀ လုံး)။ **မှတ်ချက်** – ငွေကြေးပုံစံ ပြောင်းလည်း မီနူးဈေးများ အလိုအလျောက် မပြောင်းပါ။
- [ ] **Settings → Payment names** တွင် ဆိုင်သုံး ဝေါလက်များ (KBZPay၊ Wave Pay၊ ဘဏ်လွှဲ…) ထည့်ပြီးပြီ။
- [ ] ဟင်းပွဲများတွင် **ဟင်းချက်နည်း (recipe)** ထည့်ပြီးပြီ။ (မထည့်လျှင် Business health ၏ အစားအစာကုန်ကျစရိတ် ကောင်းနေသကဲ့သို့ မှားပြမည်။)
- [ ] လစာများကို **Finance → Expenses** တွင် လစဉ် ထပ်တလဲလဲ အသုံးစရိတ်အဖြစ် သတ်မှတ်ပြီးပြီ။
- [ ] စားပွဲများ ထည့်ပြီး **Settings → Tables → Print table QR codes** ဖြင့် ပုံနှိပ်ကာ စားပွဲတိုင်းတွင် တပ်ထားသည်။

## ၅။ ဝန်ထမ်းများနှင့် ဖုန်းအစစ်ဖြင့် စမ်းပါ (၃၀ မိနစ်ခန့်)

- [ ] အော်ဒါယူ → **Send** → မီးဖိုချောင်တွင် ပေါ်သည် → **Ready** → စားပွဲထိုးဖုန်း မြည်/တုန်သည် → **Served** → ငွေရှင်း။ အဆင့်တိုင်း လိုက်စမ်းပြီးပြီ။
- [ ] Wi-Fi ကို တမင်ဖြတ်ကြည့်သည်။ **Offline · N waiting** ပေါ်ပြီး ပြန်ရလာလျှင် အော်ဒါများ ဆက်သွားသည်။ (ထိုအချိန်တွင် စာမျက်နှာကို မပိတ်ပါနှင့်။)
- [ ] ဧည့်သည်ဖုန်းဖြင့် စားပွဲ QR ကို scan ပြီး မှာကြည့်သည်။ ဈေးပါသော **options** ရွေးလို့ရသည်။
- [ ] ငွေပေးနည်း တစ်ခုစီ (ငွေသား၊ ကတ်၊ ဝေါလက်၊ ခွဲပေး၊ tip) ဖြင့် ရှင်းကြည့်ပြီး ပြေစာမှန်သည်။
- [ ] **Cash drawer → Start shift** (အံဆွဲထဲ ငွေအစစ်ရိုက်) နှင့် **Close shift** ကို လုပ်ကြည့်ပြီး ကွာခြားချက်ကို နားလည်သည်။
- [ ] ဝန်ထမ်းတိုင်းက အပေါ်ဘားရှိ **နာရီခလုတ်** ကို နှိပ်ကြည့်ပြီး ဖုန်းပေါ်တွင် ခလုတ်များ မကျော်ဘဲ ပေါ်သည်။
- [ ] **Reservations** တွင် ကြိုတင်မှာမှု တစ်ခုထည့်ပြီး စားပွဲမြေပုံတွင် ပေါ်ကြောင်း ကြည့်သည်။
- [ ] Manager PIN ဖြင့် လျှော့စျေး တစ်ခုလုပ်ကြည့်ပြီး ဝန်ထမ်း PIN ဖြင့်ကား မလုပ်နိုင်ကြောင်း ကြည့်သည်။

## ၆။ မြန်မာစာ

- [ ] မြန်မာစကားပြောသူတစ်ဦးက ဝန်ထမ်းများ နေ့စဉ်မြင်ရမည့် မျက်နှာပြင်များ (**Tables၊ Order၊ Checkout၊ Kitchen၊ နာရီခလုတ်**) ကို အရင်ဖတ်ပြီး မှားသည်များကို မှတ်ထားသည်။
- [ ] ထို့နောက် `docs/OWNER-GUIDE-my.md` နှင့် `js/i18n/my/` ထဲရှိ စာများကို ဖတ်စေပြီး ပြင်ပြီးပြီ။

## ၇။ ပထမတစ်ပတ်

- [ ] ညတိုင်း **Close shift** နှင့် **Finance → Daily close** လုပ်သည်။
- [ ] နေ့တိုင်း **System health** တွင် ⚠ မရှိကြောင်း ကြည့်သည်။
- [ ] ပထမ ၃ ရက်အတွင်း **Settings → Activity log** ကို ဖတ်ပြီး မမျှော်လင့်သော ဈေးပြောင်း၊ void၊ ဒစ်စကောင့်၊ ပိတ်ခံရသော အကောင့်များ မရှိကြောင်း စစ်သည်။
- [ ] နေ့ကုန်တွင် KBZPay/Wave တစ်ခုစီ၏ စုစုပေါင်းကို ထိုဝေါလက်၏ ကိုယ်ပိုင် app နှင့် နှိုင်းယှဉ်သည်။
- [ ] အပတ်ကုန်တွင် **Hours** တွင် *no clock-out* သတိပေးချက် ရှိမရှိ ကြည့်ပြီး ပြင်သည်။
- [ ] အပတ်ကုန်တွင် **Finance → Business health** ကိုဖွင့်ကာ သတိပေးချက်များ (ဟင်းချက်နည်းနည်းနေ၊ လစာမမှတ်ရသေး) ကို ဖတ်ပြီး ပြင်သည်။

## သိထားရန် အကန့်အသတ်များ

- စနစ်သည် PIN ကို ယုံကြည်မှုပေါ် အခြေခံသည်။ တစ်ဦး၏ PIN ဖြင့် မိတ်ဆွေအတွက် နာရီမှတ်၍ ရသည်။
- Manager PIN ရိုက်ပြီးနောက် ထို session တွင် ၁၀ မိနစ်အတွင်း လျှော့စျေး/ပယ်ဖျက်/ပြန်အမ်း အများအပြား လုပ်၍ရသည် (ဒီဇိုင်းရွေးချယ်မှု)။
- **Branches** သည် ဆိုင်ခွဲများ၏ backup ဖိုင်များကို ပေါင်းကြည့်ခြင်းသာဖြစ်ပြီး ဆာဗာချင်း တိုက်ရိုက်မချိတ်ပါ။
- **Hours** သည် လစာစနစ် မဟုတ်ပါ (အလုပ်ချိန်ဇယား၊ overtime၊ ခွင့်၊ အခွန် မပါ)။ **Tips** report က ပေးချေမှု မလုပ်ပေးပါ၊ ပေးပြီး *Finance → Expenses* တွင် မှတ်ရမည်။
